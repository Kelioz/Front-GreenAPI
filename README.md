# Telegram — GREEN-API messenger

Минималистичный интерфейс на React + TypeScript для текстовой переписки через GREEN-API. Поддерживается один активный чат по номеру телефона.

## Запуск

```bash
yarn install
yarn dev
```

Для production-сборки: `yarn build`.

## Использование

1. Нажмите **Подключить GREEN-API** и введите `idInstance` и `apiTokenInstance`.
2. Создайте чат, указав номер получателя в международном формате.
3. Отправляйте текстовые сообщения из поля ввода. Ответы отображаются в этом же чате.

Интерфейс вызывает `SendMessage`, затем опрашивает очередь через `ReceiveNotification` и подтверждает полученные уведомления методом `DeleteNotification`. Перед приемом ответов настройте инстанс для HTTP API: оставьте `webhookUrl` пустым и включите уведомления о входящих сообщениях.

Учетные данные находятся только в состоянии текущей вкладки и не сохраняются в `localStorage`. Запросы отправляются напрямую на `https://api.green-api.com`.
